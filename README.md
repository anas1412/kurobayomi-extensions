# Tsuikabako

Manga and anime sources for [Kurobayomi](https://github.com/kurobayomi/kurobayomi), the anime and manga app for the
Linux desktop.

## Add it

Open **https://tsuikabako.github.io/add** and click **Add to Kurobayomi**, or paste this address in Kurobayomi
(**Add a source repository**, or **Settings → Sources and tracking → Repositories → Add**):

```
https://raw.githubusercontent.com/tsuikabako/extensions/main/index.min.json
```

The list of sources, with their status, is at **https://tsuikabako.github.io/sources**.

## This repository is built

Everything here is written by CI from
[tsuikabako/extensions-source](https://github.com/tsuikabako/extensions-source). Report a broken source, request one or
send a change there; pull requests and issues here are not read.
